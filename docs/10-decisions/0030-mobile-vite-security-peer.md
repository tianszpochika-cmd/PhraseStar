# ADR-0030：移动端 Vite 8.2.4 的应用兼容覆盖

状态：accepted，2026-11-08；仅本应用当前依赖组合。

B153 剩余一项高危来自移动端 Vite 8.2.2。匹配的 DCloud 10.x 工具链仍声明精确 peer 8.2.2；本次保持 `3.0.0-alpha-1000920260909822` 的 App-Plus／UTS 家族，移动端直接固定 Vite 8.2.4，并只增加 `'@dcloudio/vite-plugin-uni>vite': 8.2.4` 父依赖覆盖。未改供应商代码，未关闭 peer 检查或高危门禁，也未扩大其他插件的主版本范围。

这是本应用维护的兼容决定，上游发布的 peer 仍为 8.2.2。G447 检查了插件动态加载 Vite 的路径及 plugin-vue peer 范围；四个应用类型检查／构建、680 项移动测试和 App 编译通过。Root 独立复验源码测试，并在固定 G447 H5 产物执行 G462：33 路由双主题手机检查及公开页窄屏／平板／大字共 75/75 通过。受保护页面跳转登录仅证明匿名路由，不代表登录后业务验收。

2026-11-08 Root 再次联网审计：高危 0、严重 0、中危 15、低危 10。完整 CI 和其余供应链检查仍待处理。原生编译保留 amd／import.meta 警告，正式宿主、实机、读屏以及新的登录后业务另验；G456 原检查失败原件保留。

回滚只恢复 B153 `30985b80` 中的 `apps/mobile/package.json`、`pnpm-workspace.yaml` 和 `pnpm-lock.yaml`，随后按锁安装；不撤销无关版本与源码变更。回滚会恢复已知高危，必须记录原因并继续保留门禁。后续上游适配发布后重新评估此覆盖。

审核及精确文件指纹见 [B159](../takeover/mobile-figma-20261103/reviews/INTEGRATION-B159-VITE-SECURITY.md)。
