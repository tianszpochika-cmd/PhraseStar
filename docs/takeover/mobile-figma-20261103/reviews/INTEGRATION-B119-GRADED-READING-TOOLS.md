# B119 分级阅读字号与双语键盘操作

MB-015 的字号与原文／双语控件可以用 Tab、Enter 和空格操作。字号维持 100% 至 200%，每次调整 10%。达到上下限时，相应方向退出 Tab 顺序。双语状态与正文译文显示同步，阅读跳段和词块顺序保留。 [阅读键盘与鼠标 B116](INTEGRATION-B116-READING-KEYBOARD-AND-POINTER.md)

合并后的 H5 与验收包摘要一致。受控 Chrome 通过 86 项专项断言，包含四组真实按键顺序和理解检查关闭状态。现有阅读回归 108 项，中英文两种字号的布局检查 24 组，移动端源码测试 677 项均通过。首次专项探针从词块继续 Tab，走到了下一个词块。复验使用真实 Shift+Tab 回到指定位置。 [复验回执](../evidence/ROOT-B119-GRADED-READING-TOOLS-20261106.json)
