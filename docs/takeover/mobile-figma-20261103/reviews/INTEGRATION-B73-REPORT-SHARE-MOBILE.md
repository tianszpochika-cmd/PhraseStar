# B73 移动端报告分享重试

首次主动生成时，移动端为当前报告周期生成请求标识。响应丢失或服务暂时失败时，再次点击沿用该标识。报告给出有效起始日时一并提交，旧响应缺有效日期时沿用服务缺省窗口。隐藏页面后丢弃迟到回执，保留当前周期的重试标识和已经确认的链接。预览返回仍是同一期时保留链接，读到新一期则清除旧链接与标识。撤销成功后下一次主动签发生成新标识。

同一脚本在旧 H5 用 51 项检查复现缺失请求标识和同一周报页签跨周后残留旧链接。新 H5 54 项通过，覆盖丢回执、503、预览返回、同页签跨周、撤销重签与匿名公开读取。浏览器服务端为受控模拟，真实 MySQL 的并发签发证据单列。 [B71 数据库证据](INTEGRATION-B71-REPORT-SHARE-ISSUE.md)

组合源测试 648 项、移动端类型检查、H5 与 App 源码编译通过。同一冻结 H5 的 33 条匿名路由、213 项模拟签署和 255 项关闭状态及边界检查通过。生产运行依赖支持请求标识的学习服务及 V14，部署和真机验收仍待完成。 [B73 证据](../evidence/ROOT-B73-REPORT-SHARE-MOBILE-20261105.json)
