# B106 本机测评 Kafka 传输验收

独立测评候选和 MySQL V12 运行在固定本机端口。启用发布开关后，一条符合规范的模拟 outbox 记录从待发布变为已发布，发送一次，写入发布时间并释放租约。旧格式反例保持待发布，尝试次数为零。

- 实际 Kafka 3.9.2 的 `platform.assessment.v1` 有 12 个分区。本轮读到一条记录，分区键、七个关联字段和 MySQL 中保存的 JSON 逐项一致。前后偏移量总和均为 1，未发现第二条或其他业务主题。
- 发布候选的 175 项离线测试通过，含 4 项开关检查，另有 7 项需显式运行。默认启动复验通过，检查时没有 broker 连接。首次脚本的解析检查在启动前失败，改用 Kafka 控制台默认分隔符后通过。镜像的默认卷由临时内存挂载覆盖，两个容器、专用网络、测评进程及三个端口均已释放。
