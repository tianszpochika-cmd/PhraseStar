# B92 原生安全存储源码与编译

2026-11-06。App 会话接入 UTS 安全存储。iOS 使用仅本机且解锁时可访问的 Keychain 条目。Android 6.0（API 23）及以上使用 Android Keystore 生成 AES-GCM 密钥，加密记录保存在应用私有的免备份目录。旧宿主注入仍优先，方法调用保留原宿主对象。H5 维持内存令牌和 IAM Cookie 路径。

- 独立复验 675 项移动源码测试、类型检查、正常 App 和 H5 构建。App 产物包含 748 个文件、33 条路由及两端四个 UTS 生成的原生源码文件。H5 产物包含 797 个文件，逐项排除了原生桥接标记和文件，43 个离线浏览器场景通过。
- 与编译核对使用的四个原生文件摘要一致。Android 混编实现通过实际 SDK 编译和 D8 转换，iOS 通过实际 SDK 生成 arm64 对象。两侧编译使用 DCloud 最小测试桩。Android 字节码显示先同步加密文件，再原子替换。
