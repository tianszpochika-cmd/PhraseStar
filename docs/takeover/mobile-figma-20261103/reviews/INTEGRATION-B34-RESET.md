# 找回密码页组合审核 B34

整合 Grok B20 的申请/确认页、19张原素材与双语文案；采用 DSH B09 编写的可移植界面观察器和真实会话 store 回归。Root 仅逐字节复制、审核与独立验证。重置成功不赋予成人资格或学习权限，申请回执保持条件式文案，不泄露账号是否存在；临时重置码和密码不会进入结果日志或返回链接。

Root 从独立集成工作树运行默认 H5 路径：68布局样本、8组交互、7种图标场景、37图通过，18项认证/公开文档/重置资格语义测试通过，类型与H5构建退出0。未知接口、越界请求和页面错误均0；6条控制台错误对应预期401/429/503与离线。源与构建前后稳定。该构建475文件，包含尚未签收的形象页与启动偏好修复；此处通过只计找回密码范围。

此前失败分别保留：缓存文案、异步图标就绪、近零延迟输入。最终观察器先等待原素材解码和绘制，再执行原SHA、几何与对比度断言。输入沿用已安装uni-h5的100ms同步机制：近零延迟提交仍未发送，200ms内保留焦点后提交仅一次；没有把等待后的通过称为即时提交通过。生产构建不暴露内部model、资格和pointerFeedback，资格边界由真实store的8项独立语义测试验证；界面内部字段仍标不可观测。

## B79 本机找回密码隐私

直接访问本机 IAM TLS 的找回密码入口。已注册和未知的合成账号都返回 202，公开数据及结构一致，无账号标识或令牌泄露。同键同请求重试返回相同受理数据。无效验证码确认返回 401，无新令牌，原会话通过 Gateway 仍能访问自己的资料。确认入口的 CORS 预检返回 200。独立的 29 项找回密码检查及 184 项首次签署接口检查全部通过。临时进程、MySQL、端口和证书均已释放。 [B79 证据](../evidence/ROOT-B79-LOCAL-IAM-RESET-PRIVACY-20261105.json)

另跑现有 IAM 控制器和安全事实测试共 41 项。一次性验证码、成功重置后的旧会话撤销等由内存投递测试覆盖。实际验证码送达、部署后复验及原生设备继续待验。
