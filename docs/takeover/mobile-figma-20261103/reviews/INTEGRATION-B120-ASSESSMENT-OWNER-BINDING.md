# B120 测评作答归属与版本读回

测评服务提供受保护的内部归属读取。IAM 仅在配置独立摘要后为 Learning 服务身份签发这项权限。接口校验归属、逐题编号和内容快照，区分当前与历史固定版本。 [测评固定时间 B111](INTEGRATION-B111-ASSESSMENT-PIN-TIME.md)

本机 Chrome 完成一笔语法作答，真实 MySQL 通过 17 项数据核对。随后用真实 IAM 的 Learning 服务令牌通过内部接口读回同一笔作答，版本、摘要和时间一致。匿名 401，普通学员和其他服务身份 403，错归属 404，错摘要 409。探针前后的库计数与摘要一致，七个固定端口已释放。 [复验回执](../evidence/ROOT-B120-ASSESSMENT-OWNER-BINDING-20261106.json)

IAM 与测评服务重建的安装包摘要和实际验证包一致。两套离线测试分别通过 136 项和 186 项，23 项和 7 项需显式环境的测试跳过。接口契约的 474 项操作和 836 个模型通过校验，增量兼容检查零破坏。关联 MB-013 与 MB-016 的归属前置条件，实际 Learning 消费、进度、错题详情和部署继续跟踪。 [语法作答 B110](INTEGRATION-B110-GRAMMAR-H5-KAFKA.md)
