# B112 阅读草稿数据库测试入口

原测试能被通用入口发现，但入口未能识别所需连接参数。G177 复用现有内容服务测试参数约定，以随机专用账号与数据库跑同一组校验。自动库名限定为字母和数字，授权只绑定该库。手动模式沿用既有隔离库和账号。 [MySQL 权限说明](https://dev.mysql.com/doc/refman/8.0/en/grant.html)
