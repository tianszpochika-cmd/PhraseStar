# B102 测评事件领取与租约

测评服务沿用已有 outbox 表，为 B97 的逐题事件增加存储层领取能力。批次按事件、契约和记录／信封身份筛选，旧格式和其他事件保留原状态。每次领取生成独立凭据并累计一次尝试。确认需要同一凭据和有效租约，失败或过期最多尝试五次。

- 测评服务离线测试 158 项通过，6 项需显式连接数据库。另在本机独立 MySQL 8.0 上按实际迁移版本 V12 执行 4 项，无跳过。过期和被替换凭据、尝试上限、旧行保留和两个独立连接的跳锁分别通过。临时容器、进程和端口已释放。
