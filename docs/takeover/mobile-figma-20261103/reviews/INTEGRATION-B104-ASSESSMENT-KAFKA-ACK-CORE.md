# B104 测评消息确认核心

逐题测评消息沿用注册的 `platform.assessment.v1`。发布时保留原始信封、分区键和请求关联字段。收到对应主题及有效偏移量后，才以当前租约确认；过期确认保持原状态。失败按有限次数重试，永久错误进入 owner 死信状态。

- 首版编译发现 Kafka 4.2.1 的异常类导入有误，补正后又定位到测试缺少断言导入。最终离线 171 项通过，含发布核心的 13 项受控测试，7 项需显式数据库门禁。另在独立 MySQL 8.0 上执行 5 项租约与终态测试，无跳过。
- 最终安装包在本机默认配置启动，健康检查为 UP，检查时没有 broker 连接。临时进程和端口均释放。发布开关、真实 Kafka 消息、Learning 消费及部署分别验收。 [审核回执](../evidence/ROOT-B104-ASSESSMENT-KAFKA-ACK-CORE-20261106.json)
