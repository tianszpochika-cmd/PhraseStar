# B138 成长世界的服务读取与数据库写入分离

成长世界及积分账本查询使用独立的只读事务。现有积分结算和奖励领取仍走写事务。内存适配器按原有事实生成独立副本，避免查询修改共享的奖励或积分记录。 [复验回执](../evidence/ROOT-B138-WORLD-READ-ONLY-JDBC-20261106.json)

Gamification 模块通过 67 项离线检查，2 项环境检查跳过。真实 MySQL V4 用一条可信测试完成事件及一次测试奖励领取生成事实。只具 SELECT 权限的账号成功读回摘要、连续天数、赛季、奖励和账本。另一学员为空，原写事务被数据库拒绝，前后事实一致。

首次清理采样时端口尚未确认释放。随后独立核对容器名称、标签、端口和临时测试源码均已释放。本批验收服务与数据库，世界页的真实网关与浏览器、真机、部署和逐页签收继续待验。
