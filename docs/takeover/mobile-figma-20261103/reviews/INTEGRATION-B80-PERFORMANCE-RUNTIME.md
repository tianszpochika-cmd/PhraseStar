# B80 移动端运行时画质

H5 在前台按短窗口采样帧率，每次采样之间留四秒。连续两个有效低帧率窗口才交给四档引擎逐级降档。单次长间隔被限制在测量上限，持续约 3 帧仍能达到降档条件。隐藏页面、离开前台、销毁和最低档会结束采样。原生运行时在支持注册与解除回调的情况下使用内存警告，每次有效警告降一档，后台或过期回调失效。

自动降档只作用于当前会话。保存的手动画质由显式设置处理，恢复存储、切换 B4 页面及自动档重置分别有测试。保留原动效偏好和认证启动流程。

首轮新增测试因模拟 DOM 先于 Vue 加载而失败，保留 30/41 原件。Grok 修正加载顺序，并验证持续极低帧率。修订的 42 项定向测试通过。最终冻结版本通过 661 项移动源码测试、类型检查、H5 和 App 源码构建。新 H5 的 43 个日常场景共 477 项通过。真实低配设备帧率、原生内存警告、安装包、部署及匿名性能事件投递继续待验。 [B80 证据](../evidence/ROOT-B80-MOBILE-PERFORMANCE-RUNTIME-20261105.json)

## B81 练习页共享画质
