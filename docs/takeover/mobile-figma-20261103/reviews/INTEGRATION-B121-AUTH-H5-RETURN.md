# B121 登录与注册浏览器落点

B116 H5 经本机 IAM TLS、Gateway 和 MySQL 验证。已签署合成账号从登录页提交一次，IAM 返回 200，个人页壳层可见。另一合成账号注册一次返回 201，进入新手引导，学习资格保持限制。两条链路的 Cookie 响应头和浏览器实际存储均通过 HttpOnly、Secure、SameSite=None、Partitioned 和认证路径核对。IAM 独立 HTTP 检查 184 项通过，临时资源释放。 [复验回执](../evidence/ROOT-B121-AUTH-H5-RETURN-20261106.json)

早期探针同步读取了异步 Cookie 接口。一次复验又缺少原静态服务模块。保留失败回执后补齐模块，并把异常回跳和正常登录放到独立浏览器会话。两个异常回跳仍停在登录页，未提交认证。 [新手引导 B84](INTEGRATION-B57-ONBOARDING-CONSENT.md#b84-当前-h5-签署与设备复验)

范围是登录、注册和路由落点。个人资料请求、正式协议发布、部署后入口及设备验收继续跟踪。关联 MB-001、MB-002 和 MB-023 的认证入口。
