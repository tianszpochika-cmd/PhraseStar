# B98 iOS 模拟器 Keychain

2026-11-06。用独立 UIKit 测试宿主编译 B92 的原始 Swift 安全存储实现。在 iOS 27.0 专用模拟器运行三次独立进程。系统 Keychain 的写入、替换、跨启动读回、重复删除和再次启动后的缺失检查通过。查询属性确认设备专属、解锁时可访问且不同步。

- 首次宿主缺少模拟权限，系统回执为 `-34018`。第二次把权限写入实际代码签名，模拟器安装后无法启动。第三次改用模拟器权限段，系统写入通过，Root 的回执字段校验漏掉宿主编号并提前中止。最后保留同一已签名测试二进制并修正校验，三阶段通过。[Apple 模拟器权限说明](https://developer.apple.com/forums/thread/733449)
- 四台临时模拟器均已清理，原有 11 台保留。正式 DCloud 安装宿主、Android 系统存储、真实 iOS／iPad 设备和部署继续验收。[审核回执](../evidence/ROOT-B98-IOS-SIMULATOR-KEYCHAIN-20261106.json)
