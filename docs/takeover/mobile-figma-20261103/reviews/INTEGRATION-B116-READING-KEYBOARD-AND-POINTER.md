# B116 阅读键盘、鼠标与文字放大

阅读精练和分级阅读的 H5 用户可以用 Tab 到达逐词选择，也可跳到段落导航。Enter 和 Space 可选词、切换段落或操作错误恢复。快捷按钮聚焦时独立定位，原位置不挤动正文。点击词块时即使焦点移走，鼠标仍会选中原目标。按钮在中文和英文放大时可以换行。

旧候选在两个页面上都因失焦导致词块上移 44 像素。复验最终通过 108 项受控 Chromium 操作和 8 张截图。另在 320、390 和 768 像素视口检查中英文的常规与 200% 字号，24 组文案和目标几何通过。旧 B11 恢复按钮的源码断言已更新，仍核对该按钮实际调用加载和显示原文案。
