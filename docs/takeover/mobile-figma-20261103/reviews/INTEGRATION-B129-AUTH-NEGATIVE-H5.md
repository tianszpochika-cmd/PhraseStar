# B129 登录、找回密码与注册负向 H5 验收

同一套本机真实 IAM TLS、Gateway 和独立 MySQL 上，用三个独立浏览器上下文分别操作一次。错误密码返回 401 并停留登录页，未生成 Cookie。未知账号找回返回 202，页面显示通用回执。重复注册返回 409，没有新建账号。 [复验回执](../evidence/ROOT-B129-AUTH-NEGATIVE-H5-20261106.json)

三次操作前后，测试范围内的账号、会话与重置挑战计数均保持 1、2、0。独立 IAM 的 184 项检查通过，临时进程、数据库、网络和四个端口均已释放。本批覆盖 MB-001 至 MB-003 的具名负向路径。错密后的再次登录、验证码实际送达、逐页追溯与部署继续验收。
