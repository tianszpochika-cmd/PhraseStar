# B66 报告分享撤销重试

MB-016/017 沿用学习服务的分享撤销入口。事务内按主体和租户锁定该引用，首次写入采用数据库的微秒精度，重复撤销读回首次落库时间。缺失或他人引用仍返回 404。已撤销的公开页继续只返回状态。 [证据](../evidence/ROOT-B66-REPORT-REVOKE-20261105.json)

上海时区和 UTC 分别通过同一组 12 项控制器与领域测试，覆盖首次撤销、重复读回、未落库失败、他人引用和公开字段。真实数据库并发、网关部署和签发重试分别待验。 [B62 报告页浏览器检查](INTEGRATION-B62-BOUNDARIES-AND-KEYBOARD.md)
